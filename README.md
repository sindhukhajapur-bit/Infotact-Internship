# Infotact Internship

## Project: AetherHound

### Project Overview
AetherHound is a cybersecurity project designed to detect suspicious acoustic and radio-frequency signal patterns that may indicate covert communication.

### Main Modules
- Acoustic Signal Detection
- RF Signal Simulation
- Suspicious Activity Detection
- Alert Management
- Security Monitoring Dashboard

### Technologies Used
- Python
- NumPy
- SciPy
- Streamlit
- Git and GitHub

### Development Note
RF analysis currently uses simulated data. Real RF detection requires compatible SDR hardware.
